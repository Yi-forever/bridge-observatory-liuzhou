# 桥见柳州

面向青少年的城市桥梁数字漫游与结构科普平台。项目选取柳江大桥、文惠桥、文昌大桥、白沙大桥和凤凰岭大桥，通过互动地图、结构构件讲解、车辆荷载演示和知识问答，帮助用户理解桥梁如何传力。

![桥见柳州首页](docs/previews/01-首页.png)

## 项目定位

作品将柳州的城市桥梁资源转化为可操作的工程学习材料。用户不只查看桥梁名称与年代，还可以选择构件、跟随力流、拆解结构、调节荷载，并通过桥型对比和知识挑战形成完整学习闭环。

## 核心体验

- **沿江识桥**：五座代表性桥梁组成一条时间与结构路线。
- **结构实验室**：点击构件、拖动视角、分层拆解五种桥梁模型。
- **跟随力流**：按传力顺序自动高亮桥面、承重构件、桥墩与基础。
- **荷载实验**：调节相对教学荷载，观察桥面挠度与响应状态。
- **桥型对比**：比较主要受力、关键构件、典型场景与观察问题。
- **知识挑战**：六道概念题、即时反馈、错题回顾与结果页。

## 本地运行

最简单的打开方式是双击 `start.bat`，它会直接启动作品首页。

也可以在项目目录运行本地服务：

```powershell
node server.js
```

然后访问 `http://127.0.0.1:4173`。

也可以使用 Python：

```powershell
python -m http.server 4173
```

推荐使用最新版Microsoft Edge或Google Chrome浏览器。核心功能可离线运行，不依赖数据库、后端服务或第三方运行库。

## 深链接

可以直接分享指定桥梁、显示模式和拆解状态：

```text
http://127.0.0.1:4173/#bridge=wenhui&mode=force&explode=1
```

## 技术实现

- 原生HTML、CSS和JavaScript
- 五种交互式SVG桥梁结构模型
- CSS 3D视角旋转
- Pointer Events拖动交互
- localStorage探索记录
- 响应式布局，已验证360—1440像素宽度
- 首次使用引导与键盘可操作的视角控制

## 文件说明

- `index.html`：页面结构与科普内容入口
- `styles.css`：视觉系统、响应式布局和动效
- `app.js`：桥梁数据、SVG结构模型、互动逻辑和知识问答
- `server.js`：零依赖本地静态服务器
- `start.bat`：Windows一键打开入口
- `presentation/build-deck.js`：12页路演PPT生成脚本
- `docs/previews/`：网页与交互功能预览图

## 答辩表述

“桥见柳州”将柳州“桥梁博物馆”的城市资源转化为可交互的工程教育内容。用户可以通过点击构件、跟随力流、调节荷载和比较桥型，直观看到桥面、主梁、拱肋、斜拉索、桥墩和基础之间的传力关系。

## 数据与版权说明

页面中的桥梁资料来自公开报道和科普资料，结构动画为教学简化模型，不用于工程计算。当前工程未使用外部图片、字体文件或第三方运行代码；页面预览图均为项目自身截图。
