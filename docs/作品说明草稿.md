3、作品简介

《桥见柳州——城市桥梁数字漫游与结构科普平台》以柳州“桥梁博物馆”的城市资源为切入点，面向中学生、教师与城市访客，把柳江与五座代表性桥梁（柳江大桥、文惠桥、文昌大桥、白沙大桥、凤凰岭大桥）组织成一条从城市尺度走向构件尺度的空间叙事。作品采用纯前端 Web 架构，以三维城市场景为入口：用户先在依据真实地理数据搭建的柳江与城市底图上，看到五座桥在江上的实际位置与相互关系，理解“桥为什么建在这里”。点击任意一座桥，镜头推进到该桥的三维单桥场景，可自由旋转视角、拉近观察，点选桥面、主梁、拱肋、斜拉索、桥墩与基础，理解不同桥型的传力路径；沿江落位的结构实验室与桥梁档案馆，则把观察延伸为动手实验、档案阅读与知识自测。作品以“入城—看桥—动手—测评”构成完整学习链路，把城市地标从静态介绍转化为可操作的工程知识，可服务物理与工程启蒙、学校课堂、科技馆与城市研学，具有较好的教育、文化与传播价值。同一套内容可分别用于课堂投屏演示、展馆自助体验与学生随身复习，不必为不同场合重复开发。作品同时保留完整的二维内容版本：当运行环境不支持三维渲染时，作品自动回落到二维页面，交互地图、构件讲解、跟随力流、结构拆解、荷载实验、桥型对比与知识挑战等功能仍然完整可用，保证任何环境下都能完成学习。

4、创意来源

柳州跨江桥梁数量多、桥型丰富，是学生身边可以直接观察的工程资源，但常规科普往往停留在桥名、年代与外观介绍，真正决定桥梁稳定性的结构原理被隐藏在图片和结论中。项目希望把城市本身当作一间开放的工程教室，核心创意是把“看一座桥”转化为“观察一条传力链”：通过目标引导、构件点选、力流高亮、结构拆解与参数调节，让梁桥的受弯、拱桥的受压、斜拉桥的受拉变得可见、可比较。在三维版本中，这一思路进一步落到“空间”上——城市不是背景板，而是叙事骨架：柳江在市区绕出的那道弯，本身就是五座桥为何如此分布的原因。作品因此选择用真实地理数据搭建底图，让地形与桥位自己说话，再借逐桥推进的镜头，把注意点从“城市里的桥”收拢到“桥上的构件”，形成由远及近、由整体到局部的认知顺序。作品同时结合柳州桥梁文化与工程知识，使科普内容具有城市辨识度和可迁移的教学方法。

5、运行环境

作品为纯前端静态站点，基于 HTML5、CSS3 与原生 JavaScript（ES 模块）开发，三维部分使用内置的开源渲染库 three.js（MIT 许可）绘制；不依赖后端服务、数据库或在线接口，全程离线可用，无需安装、不写入注册表、不申请管理员权限，可直接放在 U 盘或机房共享目录中运行。

桌面端（主要形态）：解压后双击启动程序即可，启动器会自动选择可用端口、内嵌并拉起本地静态服务，再以独立应用程序窗口（无地址栏、无标签页）直接进入三维城市总览；关闭窗口即退出，不在后台驻留，也无需预先安装 Node.js 或其他运行环境。若本机已安装 Microsoft Edge 或 Google Chrome，也可直接用浏览器访问 http://127.0.0.1:4173。推荐在 Windows 10/11 或常见 Linux 桌面环境下使用，屏幕分辨率建议 1366×768 以上，并确保已启用 WebGL；检测到三维渲染不可用时，作品会给出明确提示并自动切换到二维完整版本，不会黑屏。

浏览器直达：作品同时也是标准静态站点，可直接部署到任意静态托管（含校内服务器），通过网址访问而无需安装客户端，适合机房统一分发与课后复习。

课堂与展陈：作品提供面向大屏的投屏排版（放大字号与按钮、提高对比度、支持键盘快速切桥），以及面向科技馆与研学的自助体验模式（自动巡览五座桥梁与两座场馆，观众触碰即接管，长时间无操作自动复位），两种形态使用同一套内容，无需分别维护。

移动端：二维内容已适配 360—1440 像素宽度，可在平板与手机上通过浏览器直接浏览；三维场景面向桌面端，移动端会自动回落到二维版本。

探索进度与新手引导状态保存在浏览器 localStorage 中，不使用账号、不上传任何数据。三维场景支持鼠标拖动任意角度环视、滚轮以光标所在位置为中心缩放、点击桥梁或建筑聚焦，右上角可一键复位。
