# 《桥见柳州》演示视频脚本

建议时长：2 分 30 秒至 3 分钟。

录制前请先运行 `start.bat`（Windows）或 `start.sh`（Linux）以本地服务方式打开作品。直接双击 `index.html` 会进入二维完整版本，录不到三维场景。

## 00:00—00:15 问题引入

画面：三维城市总览由远及近推入，柳江在城中绕出的那道弯与五座桥依次进入画面。

旁白：

> 柳州被称为“桥梁博物馆”。但每天从桥上经过时，我们真的看见桥了吗？

## 00:15—00:40 项目介绍

画面：镜头拉高，五座桥与沿江两座场馆同框；叠加作品标题与核心功能。

旁白：

> “桥见柳州”是一套面向青少年的城市桥梁数字漫游与结构科普平台。它用真实的柳江地理数据搭起一座可以走进去的城市，再把五座代表性桥梁，一座一座推到眼前。

## 00:40—01:10 城市总览：桥为什么建在这里

操作：

1. 拖动视角，绕柳江那道弯转一圈，展示五座桥的实际位置与相互关系；
2. 依次点击柳江大桥、文惠桥、文昌大桥、白沙大桥、凤凰岭大桥，镜头逐座推进；
3. 滚轮放大某座桥所在的江段，展示它实际横跨的江面。

旁白：

> 地图不是装饰。这五座桥为什么分布在这里、彼此相隔多远、各自跨过什么样的江面，都能在场景里直接读出来。

## 01:10—01:50 走进一座桥：构件与传力

操作：

1. 点击文惠桥，镜头推进到单桥场景；
2. 点选拱肋、吊杆、桥面梁与拱座，说明面板同步给出构件职责；
3. 播放力流：桥面 → 吊杆 → 拱肋 → 拱座；
4. 拖动分层拆解，把结构一层层摊开。

旁白：

> 同一座桥，可以从整体看到局部。点开每个构件，理解它承担什么力；按下播放，看着荷载从桥面一路传向拱座。

## 01:50—02:15 结构实验室：把荷载加上去

操作：

1. 进入结构实验室，拖动「车辆荷载」滑杆，观察桥面挠度变化；
2. 切换「受力实验」模式，对比不同桥型的受力特点。

旁白：

> 改变荷载，桥会给出回应。这里所有数值都是教学用的示意比例，但它足以让学生看见：力是怎么被结构一层层分走的。

## 02:15—02:35 桥梁档案馆：从桥回到城市

操作：

1. 进入桥梁档案馆，翻阅五座桥的档案；
2. 连续回答 2 至 3 道题，展示即时反馈与最终得分。

旁白：

> 档案馆把每座桥放回它的年代与城市故事里；知识挑战则检验一件事——你到底有没有真正看懂它的传力逻辑。

## 02:35—02:55 总结与价值

画面：镜头拉回城市总览，五座桥与江湾同框；叠加资料来源与作品标题。

旁白：

> 我们希望让城市成为一本可以亲手翻开的工程书。“桥见柳州”不只介绍城市地标，更希望青少年学会从生活现象走向结构原理。

## 制作备注（录制前核对）

- **必须走本地服务**：双击 `index.html` 只会进入二维完整版本，三维镜头拍不到。
- **署名不要裁掉**：画面右下角常驻「地图数据 © OpenStreetMap contributors（ODbL 1.0）」。凡出现底图的镜头请保留该署名，这是 ODbL 的署名要求；后期裁切画面时注意不要切掉。
- **依赖未完成功能的镜头**：01:10 之后的单桥构件点选、力流、分层拆解，以及结构实验室的荷载滑杆、档案馆的答题，均按目标形态编写。若录制时尚不可用，可改为「三维总览 + 二维页面演示」的组合，或整体压缩到 1 分 30 秒，只讲城市总览与真实地理这一段。
- **可替代录制路径**：当前阶段三维场馆内景尚未建成，结构实验室与档案馆可先切换右上角「列表视图」，用现有二维页面录制档案介绍、跟随力流、结构拆解、车辆荷载实验与知识挑战，旁白无需改动。
- **术语统一**：构件名称以页面为准（拱肋 / 吊杆 / 桥面梁 / 拱座）；统一写作“力流”，不要写成“受力流”。
- **节奏控制**：每段操作不超过 4 次点击，单个画面停留不少于 3 秒，方便评委看清。
