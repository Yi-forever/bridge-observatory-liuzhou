# AI工具使用说明

## 使用工具

- Codex：用于代码结构建议、功能实现、调试、文案整理和PPT版式辅助。

实际提交前，团队应根据最终使用情况补充或删减工具名称，并与赛事官方模板中的字段保持一致。

## 使用环节

1. 项目初期：辅助梳理作品结构、页面信息架构和互动流程。
2. 开发阶段：辅助编写HTML、CSS和JavaScript代码，排查布局、事件和响应式问题。
3. 内容阶段：辅助整理桥梁结构科普表述、知识题和演示文案。
4. 展示阶段：辅助形成项目书结构和路演PPT版式。

## 人工筛选与修改

- 项目选题、目标用户、核心功能和桥型范围由团队确定。
- AI生成内容经过人工阅读、筛选、修改和最终确认。
- 页面视觉、桥梁模型、交互状态和文案需要在答辩前由团队成员完整复核。
- 提交版本中的源代码、资料来源和功能说明需由团队成员能够独立解释。

## 团队原创贡献

团队负责作品主题与需求确认、桥梁资料筛选、内容判断、功能取舍、测试验收、演示流程设计和最终提交。AI工具作为辅助开发和整理工具使用，不替代团队对作品内容、版权和技术实现的责任。

## 数据与版权

页面中的结构示意图均为项目自行绘制的SVG教学图形。引用的桥梁资料在页面“公开资料来源”中列明。作品不包含未经授权的第三方图片、字体、音乐、视频或代码。AI生成内容未直接作为桥梁史实依据，公开事实以列明资料为准。
